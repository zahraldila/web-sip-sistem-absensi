# Environment

## Tujuan

Dokumen ini menjelaskan lingkungan pengembangan (development environment) yang digunakan pada proyek SIP Sistem Absensi.

Dokumen ini akan diperbarui setelah teknologi dan tools yang digunakan dalam proyek telah ditetapkan.

---

## Development Environment

Seluruh anggota tim diharapkan menggunakan lingkungan pengembangan yang sesuai dengan kebutuhan proyek agar proses pengembangan berjalan secara konsisten.

Konfigurasi environment akan disesuaikan dengan teknologi yang digunakan pada masing-masing aplikasi.

---

## Komponen Environment

Beberapa komponen yang akan digunakan dalam proses pengembangan antara lain:

- Version Control (Git & GitHub)
- Backend Development
- Frontend Development
- Mobile Development
- Database
- Package Manager
- Containerization (Docker)
- Code Editor / IDE

Daftar tersebut akan diperbarui setelah keputusan teknologi (tech stack) ditetapkan.

---

## Konfigurasi Environment

Setiap aplikasi nantinya akan memiliki konfigurasi environment masing-masing.

Contoh konfigurasi yang akan digunakan:

- Development
- Testing
- Production

Konfigurasi tersebut akan disesuaikan dengan kebutuhan proyek.

---

## Catatan

Seluruh konfigurasi environment akan didokumentasikan lebih lanjut setelah proses perancangan sistem selesai dan tahap implementasi dimulai.
